# reetbatra.com

My site. One Next.js app, three links: [reetbatra.com](https://reetbatra.com) for everyone, [devrel.reetbatra.com](https://devrel.reetbatra.com) and [fde.reetbatra.com](https://fde.reetbatra.com) for hiring. The host decides which page you get, and the pages don't link to each other.

Black and white, light and dark. Hover my name. Press `?` for keys.

```bash
npm install
npm run dev     # localhost:3000, devrel.localhost:3000, fde.localhost:3000
npm test        # content rules + image math
```

Copy lives in `lib/content.ts`. See `AGENTS.md` for how it fits together.
